# Koe — launch film

The 42-second launch film for Koe, built with HyperFrames (HTML rendered to
video): five scenes inside a fake "Koe in 40 seconds" editor, in portrait.

- **`koe-vertical-1080x1920.mp4`** — the delivered film, 1080×1920.
- **`vertical/`** — the source. `index.html`, `hyperframes.json`,
  `compositions/` (five scenes plus a captions track), `assets/` with the
  fonts, images and the generated score. Rebuild it with the HyperFrames CLI;
  nothing is pre-baked.
- **`factcheck.md`** — every on-screen claim, its source on the live site, and
  its status.

## The voiceover is the product

The narration was generated by the hosted Koe instance itself (`POST /tts`,
poll `/job/:id`, download), on the edge engine with `en-US-EmmaNeural`, from a
free key minted for the occasion. The product narrating its own launch.

The read is a pitch, not a spec sheet: agents have no voice → Koe is where they
get one → what it is → the three moves → no account, no bill → the studio
playground → the claim.

## What is not here

The earlier landscape cut (3840×2160) and its build workspace — storyboard,
beat sheet, mix scripts, extra font families — were removed when the repository
was prepared for publication, because the portrait recomposition replaced it
and the media made up most of the repo's size. Both are still in the git
history at `cb776a7` if a landscape version is ever needed:

```bash
git show cb776a7:videos/koe-launch/koe-en-4k.mp4 > koe-en-4k.mp4
```
